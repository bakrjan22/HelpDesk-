# HelpDesk-
🛠️ HelpDesk - Atlas Solutions / Support
Application web de gestion des demandes et des incidents informatiques, conçue pour centraliser les tickets et simplifier le suivi pour les équipes de support technique.

🚀 Fonctionnalités
Création de demandes : Formulaire intuitif pour déclarer un problème informatique en spécifiant un titre, une catégorie (Réseau, Matériel, Logiciel), un niveau de priorité (Basse, Normale, Haute) et une description.

Affichage dynamique : Visualisation de la liste des demandes en temps réel avec un compteur dynamique.

Gestion des tickets : Possibilité de modifier ou de supprimer les demandes existantes.
